# Ágora — project word list for cspell
#
# Consumed as cspell's `project-words` dictionary: this path is the default value of
# `_CSPELL_DICTIONARY` in the Drupal.org gitlab_templates cspell job, registered only if the
# file exists. There is no project `.cspell.json` — see D-024(2).
#
# ENTRIES ARE JUSTIFIED, NEVER BULK-IMPORTED. The job leaves an artifact named
# `_cspell_updated_project_words.txt` — "this dictionary plus everything that just failed".
# Copying it is one command to green and an automatic red: D-024(4) forbids it by name.
# Every line below survives the question "why is this a word this project legitimately uses?",
# and the answer is on the line or in its group header.
#
# NOT here, deliberately:
#   - British-English spellings (behaviour, licence, organisation, artefacts, normalise, ...).
#     `_CSPELL_EXTRA: '--locale en,en-GB'` declares the actual language of the text and
#     `dict-en-gb-mit` is bundled on the runner. Declaring a language is not silencing a check.
#   - The verbatim Spanish quotations of [andres] in DECISIONS.md. Declaring those would make
#     them permanently correct everywhere, forever; they are scoped in place instead, with
#     cspell:disable markers around each quoted block.
#   - Real misspellings. Those get fixed, not declared — D-024(3), fourth bucket.
#
# Mechanic: cspell's dictionary parser sets `stripCaseAndAccents: true`, so a single entry
# `Ágora` also matches `ágora`/`agora`/`AGORA`, and a base form covers its possessive and
# plural. Base form listed once; no case or accent variants.
